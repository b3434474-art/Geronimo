# Geronimo Android companion

This is the phone-side Kotlin app. Use JDK 17 and Android SDK 36 to build it.

## Current calling preview (0.3.0)

- Offers a user-confirmed request to become Android's default phone app.
- Registers an Android `InCallService` to receive call events when that role is granted.
- Shows an incoming-call notification and a call screen with explicit **Answer** and **Decline** actions.
- Shows a **Hang up** action for an active call.
- Opens Android's system dialer for outgoing calls; the user reviews and places the call there.

Incoming calls are never answered automatically. No outgoing-contact allowlist is implemented yet.

## Not implemented / not verified

- Answer, decline, or hang up from the Windows desktop over BLE.
- Two-way cellular-call audio through the PC speakers and microphone.
- Reliable background notification behavior across all Android devices and battery settings.

A successful BLE connection proves only the local messaging transport. It does not prove cellular call control or audio routing.

## Setup

1. Install the APK generated by GitHub Actions.
2. Open Geronimo and grant Bluetooth permissions.
3. Tap **Set as default phone app** and confirm Android's system prompt if you want to test call-event handling.
4. Allow notifications so Geronimo can show incoming-call alerts.
5. Test with a safe, expected call. Tap Answer yourself; Geronimo does not auto-answer.

## Privacy and safety

Call control requires Android's default phone-app role. Grant it only if you want to test the feature. Call details stay on-device in this preview; no contacts or call logs are uploaded. Never commit phone numbers, contacts, or pairing secrets to the repository.
