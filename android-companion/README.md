# Geronimo Android companion

The phone-side Kotlin app works with the original Geronimo Windows assistant. Use JDK 17 and Android SDK 36 to build it.

## Features

- User-confirmed request to become Android's default phone app.
- Android `InCallService` call-state events for ringing, dialing, active and ended calls.
- Incoming call screen and notifications with manual **Answer** and **Decline**, plus **Hang up** for active calls.
- Your custom incoming and outgoing MP3 sounds, repeated until the call state changes.
- BLE notifications back to Windows with call state, caller number and available caller name.
- Answer, decline, hang up, mute, speaker and outgoing dial commands from Windows.
- Foreground connected-device service to keep the BLE phone link running while the app is in the background.
- Caller-name lookup from Android caller ID, the local trusted-number list, or phone contacts after permission is granted.
- Outgoing trusted-number list stored on the phone. Only a matching number on that phone-side list may use direct dialing, and only after Android's CALL_PHONE permission is granted. Otherwise the Android dialer opens for manual confirmation.

Incoming calls are never answered automatically. A user must tap Answer on the phone or the Windows call popup.

## Setup

1. Install the APK generated by GitHub Actions.
2. Open Geronimo and allow **Nearby devices / Bluetooth** and **Notifications** when Android asks.
3. Tap **Set as default phone app** and confirm Android's system prompt to enable call-event handling.
4. Tap **Enable caller names from contacts** to allow local contact lookups (optional).
5. Tap **Allow direct dialing for trusted contacts** only if you want the phone-side allowlist to skip the dialer screen for numbers you have personally added.
6. Keep the Geronimo phone-link foreground notification enabled. The link starts when the app opens; the Windows assistant must also press **Connect**.
7. In Windows Geronimo, open **Contacts** to add trusted outgoing numbers, then open **Calls** to dial or control an active call.
8. Test with a safe, expected call. Incoming calls still need a manual Answer action.

## Audio limitation

The BLE link sends control and call-state data only. It does not carry cellular call audio. This version does not route the phone call through the laptop microphone and speakers.

## Privacy and safety

Call state and caller lookup stay on-device and are sent only across the paired local BLE link to the companion PC. Contact permission is optional. Never commit phone numbers, contacts, or pairing secrets to the repository.
